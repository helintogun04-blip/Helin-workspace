# Frenchie Off Duty

Dog wear brand concept website / Sample Project.

Live preview: https://frenchie-off-duty-portfolio.tarthen8.chatgpt.site

## Run locally

Serve this directory with any static web server, for example:

```sh
python3 -m http.server 8000
```

Open http://localhost:8000. No installation or build step is required.

## Features

Responsive HTML/CSS, product category filters, jersey colour switching, and product detail dialogs in vanilla JavaScript. Assets are stored in assets/.

## Scope

This is a portfolio concept, not an operational store. There is no checkout, payment processing or order fulfilment. Product specifications and suitability have not been validated. Created with AI assistance and creative direction from Helin. No customer results are claimed.
